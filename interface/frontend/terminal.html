📖 Available Commands

Gradle Commands

  • gradlew build<ModelName> - Build a model
  • gradlew generate<ModelName> - Generate code only
  • gradlew compile<ModelName> - Compile only

Navigation

  • cd <path> - Change directory
  • dir or ls - List directory contents
  • pwd or get-location - Show current directory

File Viewing

  • cat <file> - Display entire file
  • head <file> - Display first 10 lines
  • head -n <num> <file> - Display first N lines
  • tail <file> - Display last 10 lines
  • tail -n <num> <file> - Display last N lines
  • type <file> - Display file (Windows style)
  • get-content <file> - Display file (PowerShell style)
  • more <file> - Display file page by page
  • less <file> - Display file with navigation

Search Commands

  • find . -name "*.txt" - Find files by name
  • grep "pattern" <file> - Search for pattern in file
  • grep -r "pattern" <dir> - Recursive search
  • select-string "pattern" <file> - PowerShell search

Environment Variables

  • set VAR=value - Set environment variable
  • $env:VAR = "value" - PowerShell env var
  • echo $VAR - Display variable value

Utilities

  • clear or cls - Clear terminal
  • help - Show this help
  • Ctrl+R - Reverse history search
  • Ctrl+C - Cancel current command
  • Ctrl+L - Clear screen

Security Note: Only MDE4CPP-related commands are allowed for security. Commands are restricted to the MDE4CPP directory structure. Access to sensitive folders (like .git, node_modules, interface/backend, etc.) is blocked.

Common MDE4CPP Workflows:

  • Navigate to example: cd src/examples/ecoreExamples/ecoreModelExample
  • Build a model: gradlew buildLibraryModel_ecore
  • View build output: cat build.log
  • Search for errors: grep -i "error" build.log
  • List generated files: ls application/bin

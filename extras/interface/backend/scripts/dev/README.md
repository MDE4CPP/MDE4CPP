# Development Testing Scripts

These scripts are for development and testing purposes only.

## test-all-models.js

Test the build service with multiple model types.

```bash
node scripts/dev/test-all-models.js
```

## test-single-model.js

Test the build service with a single model file.

```bash
node scripts/dev/test-single-model.js --file path/to/model.ecore
```

## Note

These scripts are not required for production use. They are provided for development and testing purposes.
